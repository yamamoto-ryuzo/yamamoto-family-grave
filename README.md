# 山本家 先祖墓 構想メモ

山本家の先祖墓の構想をまとめたページです。確定仕様・検討中の想定・レイアウト案・石材店との協議事項を管理しています。

## 公開ページ（GitHub Pages）

- https://yamamoto-ryuzo.github.io/yamamoto-family-grave/
- [構想メモ](https://yamamoto-ryuzo.github.io/yamamoto-family-grave/index.html)
- [石の色選び](https://yamamoto-ryuzo.github.io/yamamoto-family-grave/color.html)

## ページ構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 構想メモ本体（確定仕様・未確定事項・レイアウト・墓石形式・協議事項） |
| `color.html` | 墓石の色選び（実石サンプル写真つき10色系統の比較・拡大表示） |
| `images/` | 家紋・墓石形式イメージ・石材サンプル写真 |
